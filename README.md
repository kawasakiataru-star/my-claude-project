# KAWASAKI — Personal Profile Site

「専門性を持ちながら、できるだけ自由に生きる。」をコンセプトにした、ストーリー型のプロフィールサイトです。
ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）です。

## 構成

```
index.html          ページ本体（17セクション）
assets/css/style.css
assets/js/main.js   メニュー・スクロール演出・レーダーチャート
assets/img/         画像（WebP、位置情報などのメタデータは除去済み）
```

## 確認方法

`index.html` をブラウザで開くだけで表示できます。

## 公開方法（GitHub Pages）

Settings → Pages → Source を「Deploy from a branch」、ブランチを選び `/ (root)` を指定。

## プライバシー方針

住所・勤務先・連絡先・利用者情報・健康情報・正確な資産額などは掲載していません。
第三者が写っている写真は使用していません。
