# パラエストラ田無｜池田柔術男塾道場 ホームページ（サンプル）

| ファイル | 用途 |
| --- | --- |
| `index.html` | サイト本体。`images/` の写真を読み込む（サーバーに置く場合はこちら） |
| `images/` | 掲載写真（圧縮済み JPEG） |
| `dist/paraestra-tanashi.html` | 写真を埋め込んだ1ファイル版。メール・LINEでそのまま渡せる |
| `tools/build_single.py` | `index.html` を編集したあと `python3 tools/build_single.py` で1ファイル版を作り直す |

## 掲載内容
ヒーロー / 道場について / クラス紹介（6種）/ 週間スケジュール / 入会・料金 / 塾長紹介 / 写真 / 無料体験の流れ / FAQ / アクセス / お問い合わせフォーム
