# ミニマム柔術クラブ ホームページ（素案）

初心者向けの小さな柔術・グラップリング道場「ミニマム柔術クラブ」のホームページ素案です。

- `index.html` … そのままブラウザで開けるページ本体
- `page.html` … Claude Artifact 公開用（`<head>` などを省いた版。内容は index.html と同じ）
- `img/` … 写真（元画像を縮小・WebP化したもの）

## 未確定のため仮で入れている項目
- 場所・住所・アクセス
- 料金（「案・未確定」と表示）
- クラススケジュール（曜日・時間）
- 体験申込フォームの送信先（現在は見本。Googleフォーム／LINE公式等に接続予定）
